# GREED PIT

GREED PIT is a mobile-first portrait survival/action game targeting iOS and Android, with an HTML5 PC/browser distribution build for itch.io.

## itch.io / PC-browser release hardening

The dedicated itch package is generated by `tools/build_greed_pit_itch.py` from the verified 0.20.13 source. It adds desktop-friendly controls while preserving touch support:

- WASD / arrow-key movement
- Escape pause/resume
- mouse menus
- pointer-drag movement fallback
- desktop landscape support
- service worker disabled inside the itch package to avoid stale embedded-cache behavior

The current audio path is hardened for browser distribution:

- lazy bounded SFX pools (`2` voices per effect instead of eager larger pools)
- music begins with metadata preload and primes on real keyboard/pointer interaction
- autoplay rejection is retried only from a later user gesture
- per-event duplicate SFX throttles remain active
- unused connection-test audio is excluded from the shipping package
