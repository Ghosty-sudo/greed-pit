# GREED PIT — App Store screenshot plan

Target a single high-resolution iPhone portrait set first so App Store Connect can scale it for smaller supported iPhone displays.

## Export target

- Format: PNG or JPEG
- Portrait size target: `1320 x 2868`
- No alpha channel / transparency
- Capture from the actual native iPhone build or simulator at an accepted resolution
- Do not fake controls, rewards, enemies, or gameplay that are not present in the submitted build

## Recommended first five screenshots

1. **Core combat** — active run with enemies, XP, projectiles, health/hype HUD, and readable action.
   - Caption concept: `DROP IN. BUILD FAST.`
2. **Upgrade choice** — three upgrade cards visible with Current Build context.
   - Caption concept: `STACK BAD IDEAS.`
3. **GREED contract** — contract choice showing the power/consequence tradeoff.
   - Caption concept: `POWER HAS A PRICE.`
4. **Cycle decision** — Cash Out / Go Deeper screen with haul multiplier.
   - Caption concept: `CASH OUT — OR GO DEEPER.`
5. **Progression** — Bad Ideas or Skins screen showing persistent unlocks.
   - Caption concept: `BRING SOMETHING BACK.`

## Optional additions

6. Boss encounter / Tax Collector.
7. Hype mode or high-density late-run combat.
8. Continue Saved Run / mobile recovery feature.

## Capture gate

Do not treat screenshots as final until the same native candidate has passed the real-iPhone performance test, because UI or performance fixes after capture can make store screenshots stale.
