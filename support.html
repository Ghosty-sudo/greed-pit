GREED PIT Support

Support information for the GREED PIT mobile game.

Before reporting a problem

Close and reopen the app if the game stops responding. If a run was checkpointed, use CONTINUE SAVED RUN from the title screen. Keep the device in portrait orientation during play.

Performance issues

If gameplay slows down during a run, include the approximate run timer, level, cycle, and what was happening on screen when the slowdown began. Those details help reproduce performance problems.
